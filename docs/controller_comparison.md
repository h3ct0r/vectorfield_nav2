# Controller comparison

:::{note}
Planned for M6. `vectorfield_system_tests/benchmarks/compare_controllers.py` will run the M3
route on the Jazzy loopback simulation with this controller, Regulated Pure Pursuit, MPPI and
the Graceful controller, using identical limits and five runs each. It will report the
cross-track error (RMS and maximum), the time to goal and the RMS jerk, and regenerate this page
from the recorded run.
:::

# C++ API reference

:::{note}
Planned for M1 (`vectorfield_core`) and M2 (`vectorfield_ros` and
`vectorfield_nav2_controller`). The reference is built from the public headers by Doxygen and
rendered here through Breathe, with curated entries for the main classes. The core C++ and
Python APIs are experimental throughout the 0.x series; the stable surfaces are the plugin
type, parameter names, topic and action names, and the message definitions.
:::

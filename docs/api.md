# C++ API reference

The reference is generated by Doxygen from the public headers of `vectorfield_core`,
`vectorfield_ros` and `vectorfield_nav2_controller`, and rendered here with Breathe. This page
lists the main entry points; every other type is documented in its header.

:::{note}
The core C++ and Python APIs are experimental throughout the 0.x series. The stable surfaces are
the plugin type, the parameter names and their meaning, the topic and action names, and the
message definitions.
:::

To build the reference locally, run Doxygen before Sphinx (see {doc}`contributing`):

```bash
(cd docs && doxygen Doxyfile)
sphinx-build -W --keep-going -b html docs docs/_build/html
```
